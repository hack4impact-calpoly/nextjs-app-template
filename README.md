## commit statements
write commit statements like you're explaining what you just did to someone who has no clue what you just did (because you are). commit statements are how you explain changes to others reviewing your code, and to your future self.

the "action: description" template is a good place to start:
* "add: readme updates"
* "fix: date formatting on events"
* "add: student type interface"

## database connection
when we work on connecting our frontend to our backend via API endpoints, we'll want to start working with real data -- that data has to live somewhere. enter: MongoDB! MongoDB is a friendly, commonly-used database service we'll use during bootcamp. it is something we'll configure access to in milestone #2. if they don't cover it in bootcamp, I (your humble tech lead) will help you!

### IMPORTANT!!!
when you connect to the database, you will generate an API key, which we will refer to here as a MONGO_URI. this will go in your local repo in a .env folder. it is absolutely ESSENTIAL that this MONGO_URI does not get pushed to the remote repository (the remote repository is the one you're looking at now -- the collective and public one). to do this, ensure you have a .gitignore in your root repository, and that the .gitignore contains '.env'. if you clone the repo correctly, this should already be configured, but please double check before pushing anything.

## using the project board
we'll track our progress on the fancy-shmancy Github Project Board (woohoo!!! isn't that so exciting!) you can find it at "projects" along the top menu. it contains 5 task stages:
* backlog: tasks we have planned but not started
* in progress: this task is being worked on!
* in review: tech lead is reviewing your code!
* done: merged into the main repo = changes accepted and applied

## comments
commenting your code is not aaalllways necessary, but can be very helpful -- especially when you know others will read your code (which is usually the case). there are many different ways to write both good and bad code comments.
